## 安装

先按[开始使用](/)配置组件仓库。

```sh
npx shadcn add @conteman/card
```

## Props

| 参数       | 行为                                             |
| ---------- | ------------------------------------------------ |
| `size`     | default / sm；控制卡片内边距与内容间距。 |
| `children` | ReactNode，调用方提供的组合内容。                |

导出：`Card`、`CardHeader`、`CardFooter`、`CardTitle`、`CardAction`、`CardDescription`、`CardContent`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import { useState } from "react";
import * as UI from "@/components/ui/card";
import { Button } from "@/components/ui/button";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  const [empty, setEmpty] = useState(false);
  return (
    <div
      id="preview"
      data-demo="card"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.Card>
        <UI.CardHeader>
          <UI.CardTitle>{text("偏好设置", "Preferences")}</UI.CardTitle>
          <UI.CardDescription>
            {text("此处展示组合插槽", "Composed slots example")}
          </UI.CardDescription>
        </UI.CardHeader>
        <UI.CardContent>
          <p>
            {text("内容由调用方提供。", "Content is supplied by the caller.")}
          </p>
        </UI.CardContent>
        <UI.CardFooter>
          <Button variant="outline" onClick={() => setEmpty(!empty)}>
            {empty ? text("已保存", "Saved") : text("保存", "Save")}
          </Button>
        </UI.CardFooter>
      </UI.Card>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
