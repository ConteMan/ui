## 安装

先按[开始使用](/)配置组件仓库。

```sh
npx shadcn add @conteman/table
```

## Props

| 参数        | 行为                                     |
| ----------- | ---------------------------------------- |
| `children`  | ReactNode，调用方提供的组合内容。        |
| `className` | string；合并到组件根元素的 Tailwind 类。 |

导出：`Table`、`TableHeader`、`TableBody`、`TableFooter`、`TableHead`、`TableRow`、`TableCell`、`TableCaption`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import * as UI from "@/components/ui/table";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="table"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.Table aria-label={text("示例清单", "Example inventory")}>
        <UI.TableCaption>
          {text("示例数据", "Illustrative data")}
        </UI.TableCaption>
        <UI.TableHeader>
          <UI.TableRow>
            <UI.TableHead>{text("名称", "Name")}</UI.TableHead>
            <UI.TableHead>{text("状态", "Status")}</UI.TableHead>
          </UI.TableRow>
        </UI.TableHeader>
        <UI.TableBody>
          {["Button", "Input", "Table"].map((name) => (
            <UI.TableRow key={name}>
              <UI.TableCell>{name}</UI.TableCell>
              <UI.TableCell>{text("可使用", "Available")}</UI.TableCell>
            </UI.TableRow>
          ))}
        </UI.TableBody>
      </UI.Table>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
