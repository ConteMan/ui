## Props

| 参数                          | 行为                                                       |
| ----------------------------- | ---------------------------------------------------------- |
| `title / secondary / actions` | ReactNode；标题、副信息与操作区，窄屏自动换行。            |
| `label / children`            | 调用方提供的文案或可访问名称，不内置默认文字。             |
| `copiedLabel / failedLabel`   | 调用方提供的文案或可访问名称，不内置默认文字。             |
| `format / empty`              | format(iso) 返回展示内容；empty 提供无效或缺失时间的内容。 |

导出：`PageHeader`、`DescriptionList`、`DescriptionItem`、`CopyableId`、`StatusBadge`、`MenuAction`、`ActionsMenu`、`TimeTooltip`、`FinalFocus`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import { useState } from "react";
import * as UI from "@/components/detail";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  const [empty, setEmpty] = useState(false);
  return (
    <div
      id="preview"
      data-demo="detail"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <div className="space-y-4">
        <UI.PageHeader
          title={text("示例项目", "Example project")}
          secondary="Project 001"
          status={
            <UI.StatusBadge>{text("可使用", "Available")}</UI.StatusBadge>
          }
          copy={
            <UI.CopyableId
              value="project-001"
              label={text("复制编号", "Copy ID")}
              copiedLabel={text("已复制", "Copied")}
              failedLabel={text("复制失败", "Copy failed")}
            />
          }
        />
        <UI.DescriptionList>
          <UI.DescriptionItem label={text("名称", "Name")}>
            Example
          </UI.DescriptionItem>
          <UI.DescriptionItem label={text("版本", "Version")}>
            1.0.0
          </UI.DescriptionItem>
        </UI.DescriptionList>
        <UI.ActionsMenu
          label={text("操作", "Actions")}
          actions={[
            {
              label: text("查看详情", "View details"),
              onSelect: () => setEmpty(!empty),
            },
          ]}
        />
        {empty && (
          <p role="status">{text("已打开详情预览", "Detail preview opened")}</p>
        )}
      </div>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
