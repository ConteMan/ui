## 安装

先按[开始使用](/)配置组件仓库。

```sh
npx shadcn add @conteman/chart
```

## Props

| 参数       | 行为                                          |
| ---------- | --------------------------------------------- |
| `config`   | ChartConfig；系列名称、图标和浅深色颜色映射。 |
| `children` | ReactNode，调用方提供的组合内容。             |
| `id`       | string；原生元素标识，用于关联 Label 与反馈。 |

导出：`ChartConfig`、`ChartContainer`、`ChartTooltip`、`ChartTooltipContent`、`ChartLegend`、`ChartLegendContent`、`ChartStyle`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import * as UI from "@/components/ui/chart";
import { AreaChart, Area, XAxis, YAxis } from "recharts";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="chart"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <div className="space-y-4">
        <UI.ChartContainer
          config={{
            count: { label: text("访问量", "Visits"), color: "var(--chart-1)" },
          }}
          className="h-64 w-full"
        >
          <AreaChart
            data={[
              { day: "Mon", count: 12 },
              { day: "Tue", count: 28 },
              { day: "Wed", count: 19 },
              { day: "Thu", count: 42 },
            ]}
            accessibilityLayer
          >
            <XAxis dataKey="day" />
            <YAxis />
            <UI.ChartTooltip content={<UI.ChartTooltipContent />} />
            <Area
              dataKey="count"
              stroke="var(--color-count)"
              fill="var(--color-count)"
            />
          </AreaChart>
        </UI.ChartContainer>
        <p>
          {text(
            "示例访问量；方向键浏览数据点。",
            "Illustrative visits; use arrow keys to inspect points.",
          )}
        </p>
      </div>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
