## Props

| 参数        | 行为                                                |
| ----------- | --------------------------------------------------- |
| `data`      | 示例数据数组，不内置请求。                          |
| `label`     | 调用方提供的文案或可访问名称，不内置默认文字。      |
| `empty`     | ReactNode；无数据内容由调用方提供。                 |
| `formatDay` | (day: string) => string；格式化横轴、提示中的日期。 |

导出：`Trend`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import { useState } from "react";
import * as UI from "@/components/trend";
import { Button } from "@/components/ui/button";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  const [empty, setEmpty] = useState(false);
  return (
    <div
      id="preview"
      data-demo="trend"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <div className="space-y-4">
        <UI.Trend
          label={text("访问趋势", "Visit trend")}
          empty={text("没有数据", "No data")}
          data={
            empty
              ? []
              : [
                  { day: "Mon", count: 12 },
                  { day: "Tue", count: 28 },
                  { day: "Wed", count: 19 },
                  { day: "Thu", count: 42 },
                ]
          }
        />
        <Button
          variant="outline"
          aria-pressed={empty}
          onClick={() => setEmpty(!empty)}
        >
          {text("切换空状态", "Toggle empty state")}
        </Button>
      </div>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
