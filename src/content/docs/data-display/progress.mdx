
## Props

| 参数       | 行为                                                    |
| ---------- | ------------------------------------------------------- |
| `value`    | 沿用底层组件的受控值或初始默认值。                      |
| `max`      | number；进度上限，默认 100；value=null 表示不确定进度。 |
| `children` | ReactNode，调用方提供的组合内容。                       |

导出：`Progress`、`ProgressTrack`、`ProgressIndicator`、`ProgressLabel`、`ProgressValue`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import { useState } from "react";
import * as UI from "@/components/ui/progress";
import { Button } from "@/components/ui/button";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  const [amount, setAmount] = useState(30);
  return (
    <div
      id="preview"
      data-demo="progress"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <div className="space-y-5">
        <UI.Progress value={amount} aria-label={text("完成进度", "Completion")}>
          <UI.ProgressLabel>{text("完成进度", "Completion")}</UI.ProgressLabel>
          <UI.ProgressValue />
        </UI.Progress>
        <Button
          variant="outline"
          onClick={() => setAmount(amount >= 100 ? 0 : amount + 10)}
        >
          {text("增加 10%", "Add 10%")}
        </Button>
        <UI.Progress value={null} aria-label={text("准备中", "Preparing")} />
      </div>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
