## Props

| 参数                   | 行为                                           |
| ---------------------- | ---------------------------------------------- |
| `options`              | 带 value、label 及可选 disabled 的选项数组。   |
| `value / defaultValue` | 沿用底层组件的受控值或初始默认值。             |
| `onValueChange`        | 变更或提交回调，副作用由应用处理。             |
| `label / aria-label`   | 调用方提供的文案或可访问名称，不内置默认文字。 |

导出：`SegmentedOption`、`SegmentedControl`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import { useState } from "react";
import * as UI from "@/components/segmented-control";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  const [choice, setChoice] = useState("weekly");
  return (
    <div
      id="preview"
      data-demo="segmented-control"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <div className="space-y-4">
        <UI.SegmentedControl
          label={text("显示方式", "Display mode")}
          options={[
            { value: "weekly", label: text("每周", "Weekly") },
            { value: "daily", label: text("每日", "Daily") },
            {
              value: "off",
              label: text("不可用", "Unavailable"),
              disabled: true,
            },
          ]}
          value={choice}
          onValueChange={setChoice}
        />
        <p role="status">{choice}</p>
        <UI.SegmentedControl
          aria-label={text("禁用显示方式", "Disabled display mode")}
          disabled
          options={[
            { value: "weekly", label: text("每周", "Weekly") },
            { value: "daily", label: text("每日", "Daily") },
          ]}
        />
      </div>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
