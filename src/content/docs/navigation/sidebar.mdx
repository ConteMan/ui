
## Props

| 参数                              | 行为                                                 |
| --------------------------------- | ---------------------------------------------------- |
| `open / defaultOpen`              | boolean；受控打开状态或非受控初始状态。              |
| `onOpenChange`                    | 变更或提交回调，副作用由应用处理。                   |
| `collapsible`                     | offcanvas / icon / none；侧栏收起方式。              |
| `mobileTitle / mobileDescription` | string；移动侧栏标题必填，说明可选，用于对话框命名。 |

导出：`Sidebar`、`SidebarContent`、`SidebarFooter`、`SidebarGroup`、`SidebarGroupAction`、`SidebarGroupContent`、`SidebarGroupLabel`、`SidebarHeader`、`SidebarInput`、`SidebarInset`、`SidebarMenu`、`SidebarMenuAction`、`SidebarMenuBadge`、`SidebarMenuButton`、`SidebarMenuItem`、`SidebarMenuSkeleton`、`SidebarMenuSub`、`SidebarMenuSubButton`、`SidebarMenuSubItem`、`SidebarProvider`、`SidebarRail`、`SidebarSeparator`、`SidebarTrigger`、`useSidebar`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import { useState } from "react";
import * as UI from "@/components/ui/sidebar";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  const [selected, setSelected] = useState(1);
  return (
    <div
      id="preview"
      data-demo="sidebar"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.SidebarProvider className="min-h-0">
        <UI.Sidebar
          collapsible="none"
          mobileTitle={text("导航", "Navigation")}
          className="w-full"
        >
          <UI.SidebarHeader>
            {text("示例工作区", "Example workspace")}
          </UI.SidebarHeader>
          <UI.SidebarContent>
            <UI.SidebarGroup>
              <UI.SidebarGroupLabel>
                {text("工作", "Workspace")}
              </UI.SidebarGroupLabel>
              <UI.SidebarGroupContent>
                <UI.SidebarMenu>
                  {[text("概览", "Overview"), text("项目", "Projects")].map(
                    (label, index) => (
                      <UI.SidebarMenuItem key={label}>
                        <UI.SidebarMenuButton
                          isActive={selected === index}
                          onClick={() => setSelected(index)}
                          className="min-h-11"
                        >
                          {label}
                        </UI.SidebarMenuButton>
                      </UI.SidebarMenuItem>
                    ),
                  )}
                </UI.SidebarMenu>
              </UI.SidebarGroupContent>
            </UI.SidebarGroup>
          </UI.SidebarContent>
          <UI.SidebarFooter>
            {text(
              "基础分组示例，可组合为后台外壳。",
              "Primitive groups for composing an admin shell.",
            )}
          </UI.SidebarFooter>
        </UI.Sidebar>
      </UI.SidebarProvider>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。

Sidebar 提供基础分组。需要分组侧栏、页面吸顶区与手机导航的完整组合，见[后台外壳](/patterns/admin-shell/)。
