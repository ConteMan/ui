## 安装

先按[开始使用](/)配置组件仓库。

```sh
npx shadcn add @conteman/accordion
```

## Props

| 参数                   | 行为                                          |
| ---------------------- | --------------------------------------------- |
| `value / defaultValue` | 沿用底层组件的受控值或初始默认值。            |
| `onValueChange`        | 变更或提交回调，副作用由应用处理。            |
| `multiple`             | boolean；启用多值选择，value 与回调使用数组。 |
| `disabled`             | boolean；禁用交互，默认 false。               |

导出：`Accordion`、`AccordionItem`、`AccordionTrigger`、`AccordionContent`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import * as UI from "@/components/ui/accordion";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="accordion"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.Accordion defaultValue={["install"]}>
        <UI.AccordionItem value="install">
          <UI.AccordionTrigger>
            {text("如何安装？", "How do I install it?")}
          </UI.AccordionTrigger>
          <UI.AccordionContent>
            {text(
              "运行本页提供的 shadcn 安装命令。",
              "Run the shadcn installation command on this page.",
            )}
          </UI.AccordionContent>
        </UI.AccordionItem>
        <UI.AccordionItem value="theme">
          <UI.AccordionTrigger>
            {text("支持深色吗？", "Does it support dark mode?")}
          </UI.AccordionTrigger>
          <UI.AccordionContent>
            {text(
              "支持，切换根元素的 dark 类。",
              "Yes. Toggle the dark class on the root element.",
            )}
          </UI.AccordionContent>
        </UI.AccordionItem>
        <UI.AccordionItem value="disabled" disabled>
          <UI.AccordionTrigger>
            {text("不可用", "Unavailable")}
          </UI.AccordionTrigger>
          <UI.AccordionContent />
        </UI.AccordionItem>
      </UI.Accordion>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
