## 安装

```sh
npx shadcn add @conteman/tabs
```

## Props

| 参数                   | 行为                                                                   |
| ---------------------- | ---------------------------------------------------------------------- |
| `value / defaultValue` | 沿用底层组件的受控值或初始默认值。                                     |
| `onValueChange`        | 变更或提交回调，副作用由应用处理。                                     |
| `orientation`          | horizontal / vertical；Field 另支持 responsive；按组件决定布局或方向。 |

导出：`Tabs`、`TabsList`、`TabsTrigger`、`TabsContent`、`tabsListVariants`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import * as UI from "@/components/ui/tabs";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="tabs"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.Tabs defaultValue="overview">
        <UI.TabsList aria-label={text("项目面板", "Project panels")}>
          <UI.TabsTrigger value="overview">
            {text("概览", "Overview")}
          </UI.TabsTrigger>
          <UI.TabsTrigger value="details">
            {text("详情", "Details")}
          </UI.TabsTrigger>
          <UI.TabsTrigger value="disabled" disabled>
            {text("不可用", "Unavailable")}
          </UI.TabsTrigger>
        </UI.TabsList>
        <UI.TabsContent value="overview">
          {text("项目概览内容。", "Project overview content.")}
        </UI.TabsContent>
        <UI.TabsContent value="details">
          {text("项目详情内容。", "Project details content.")}
        </UI.TabsContent>
      </UI.Tabs>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
