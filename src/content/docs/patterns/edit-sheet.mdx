## Props

| 参数                                                 | 行为                                                                  |
| ---------------------------------------------------- | --------------------------------------------------------------------- |
| `open / onOpenChange`                                | 变更或提交回调，副作用由应用处理。                                    |
| `title / description`                                | ReactNode；页头标题与可选说明。                                       |
| `saveLabel / savingLabel / cancelLabel / closeLabel` | 调用方提供的文案或可访问名称，不内置默认文字。                        |
| `saving / error`                                     | boolean / ReactNode；保存中禁止关闭和重复提交，错误内容由调用方提供。 |
| `onSave`                                             | 变更或提交回调，副作用由应用处理。                                    |

导出：`EditSheet`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import { useId } from "react";
import * as UI from "@/components/ui/sheet";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);
  const id = useId();
  return (
    <div
      id="preview"
      data-demo="sheet"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.Sheet>
        <UI.SheetTrigger render={<Button className="min-h-11" />}>
          {text("打开侧面板", "Open sheet")}
        </UI.SheetTrigger>
        <UI.SheetContent closeLabel={text("关闭", "Close")}>
          <UI.SheetHeader>
            <UI.SheetTitle>{text("编辑项目", "Edit project")}</UI.SheetTitle>
            <UI.SheetDescription>
              {text(
                "通过 Escape 或关闭按钮返回。",
                "Use Escape or the close button to return.",
              )}
            </UI.SheetDescription>
          </UI.SheetHeader>
          <div className="grid gap-3 p-4">
            <Label htmlFor={id}>{text("名称", "Name")}</Label>
            <Input id={id} defaultValue="Example" />
          </div>
          <UI.SheetFooter>
            <UI.SheetClose render={<Button />}>
              {text("完成", "Done")}
            </UI.SheetClose>
          </UI.SheetFooter>
        </UI.SheetContent>
      </UI.Sheet>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
