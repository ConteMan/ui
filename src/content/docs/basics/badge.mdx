```sh
npx shadcn add @conteman/badge
```

## Props

| 参数       | 行为                                        |
| ---------- | ------------------------------------------- |
| `variant`  | default / secondary / destructive / outline |
| `children` | ReactNode，调用方提供的组合内容。           |

导出：`Badge`、`badgeVariants`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import * as UI from "@/components/ui/badge";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="badge"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <div className="flex flex-wrap gap-3">
        {(["default", "secondary", "outline", "destructive"] as const).map(
          (variant) => (
            <UI.Badge key={variant} variant={variant}>
              {text("状态", "Status")} · {variant}
            </UI.Badge>
          ),
        )}
      </div>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
