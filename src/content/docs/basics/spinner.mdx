## 安装

先按[开始使用](/)配置组件仓库。

```sh
npx shadcn add @conteman/spinner
```

## Props

| 参数         | 行为                                           |
| ------------ | ---------------------------------------------- |
| `aria-label` | 调用方提供的文案或可访问名称，不内置默认文字。 |
| `className`  | string；合并到组件根元素的 Tailwind 类。       |

导出：`Spinner`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import * as UI from "@/components/ui/spinner";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="spinner"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <div className="flex flex-wrap items-center gap-5">
        <UI.Spinner aria-label={text("加载中", "Loading")} />
        <UI.Spinner className="size-6" aria-label={text("同步中", "Syncing")} />
        <span role="status">{text("正在准备预览…", "Preparing preview…")}</span>
      </div>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
