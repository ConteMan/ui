## Props

| 参数                 | 行为                                                |
| -------------------- | --------------------------------------------------- |
| `open / defaultOpen` | boolean；受控打开状态或非受控初始状态。             |
| `onOpenChange`       | 变更或提交回调，副作用由应用处理。                  |
| `closeLabel`         | 调用方提供的文案或可访问名称，不内置默认文字。      |
| `showCloseButton`    | boolean；控制关闭图标；同时提供 closeLabel 才显示。 |

导出：`Dialog`、`DialogClose`、`DialogContent`、`DialogDescription`、`DialogFooter`、`DialogHeader`、`DialogOverlay`、`DialogPortal`、`DialogTitle`、`DialogTrigger`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import { useState } from "react";
import * as UI from "@/components/ui/dialog";
import { Button } from "@/components/ui/button";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  const [, setEmpty] = useState(false);
  return (
    <div
      id="preview"
      data-demo="dialog"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.Dialog>
        <UI.DialogTrigger render={<Button className="min-h-11" />}>
          {text("打开弹层", "Open dialog")}
        </UI.DialogTrigger>
        <UI.DialogContent closeLabel={text("关闭", "Close")}>
          <UI.DialogHeader>
            <UI.DialogTitle>
              {text("确认更改", "Confirm changes")}
            </UI.DialogTitle>
            <UI.DialogDescription>
              {text(
                "此操作仅更新预览状态。",
                "This action only updates the preview.",
              )}
            </UI.DialogDescription>
          </UI.DialogHeader>
          <UI.DialogFooter>
            <UI.DialogClose render={<Button variant="outline" />}>
              {text("取消", "Cancel")}
            </UI.DialogClose>
            <UI.DialogClose render={<Button onClick={() => setEmpty(true)} />}>
              {text("确认", "Confirm")}
            </UI.DialogClose>
          </UI.DialogFooter>
        </UI.DialogContent>
      </UI.Dialog>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。

内置关闭按钮仅在传入 closeLabel 时显示；否则自行组合带文案的 Close 控件。
