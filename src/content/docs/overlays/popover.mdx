
## Props

| 参数                 | 行为                                                     |
| -------------------- | -------------------------------------------------------- |
| `open / defaultOpen` | boolean；受控打开状态或非受控初始状态。                  |
| `onOpenChange`       | 变更或提交回调，副作用由应用处理。                       |
| `side / align`       | 弹层方向 top/right/bottom/left 与对齐 start/center/end。 |
| `children`           | ReactNode，调用方提供的组合内容。                        |

导出：`Popover`、`PopoverContent`、`PopoverDescription`、`PopoverHeader`、`PopoverTitle`、`PopoverTrigger`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import { useId } from "react";
import * as UI from "@/components/ui/popover";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);
  const id = useId();
  return (
    <div
      id="preview"
      data-demo="popover"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.Popover>
        <UI.PopoverTrigger
          render={<Button variant="outline" className="min-h-11" />}
        >
          {text("打开选项", "Open options")}
        </UI.PopoverTrigger>
        <UI.PopoverContent>
          <UI.PopoverTitle>
            {text("显示选项", "Display options")}
          </UI.PopoverTitle>
          <UI.PopoverDescription>
            {text("选项由调用方定义。", "Options are defined by the caller.")}
          </UI.PopoverDescription>
          <Label htmlFor={id}>{text("名称", "Name")}</Label>
          <Input id={id} defaultValue="Example" />
        </UI.PopoverContent>
      </UI.Popover>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
