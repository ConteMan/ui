## 安装

先按[开始使用](/)配置组件仓库。

```sh
npx shadcn add @conteman/tooltip
```

## Props

| 参数           | 行为                                                     |
| -------------- | -------------------------------------------------------- |
| `delay`        | number；TooltipProvider 悬停后打开的毫秒延迟。           |
| `children`     | ReactNode，调用方提供的组合内容。                        |
| `side / align` | 弹层方向 top/right/bottom/left 与对齐 start/center/end。 |

导出：`Tooltip`、`TooltipTrigger`、`TooltipContent`、`TooltipProvider`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import * as UI from "@/components/ui/tooltip";
import { Button } from "@/components/ui/button";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="tooltip"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.TooltipProvider>
        <UI.Tooltip>
          <UI.TooltipTrigger
            render={<Button variant="outline" className="min-h-11" />}
          >
            {text("悬停或聚焦", "Hover or focus")}
          </UI.TooltipTrigger>
          <UI.TooltipContent>
            {text(
              "键盘焦点同样显示说明。",
              "Keyboard focus also reveals this hint.",
            )}
          </UI.TooltipContent>
        </UI.Tooltip>
      </UI.TooltipProvider>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
