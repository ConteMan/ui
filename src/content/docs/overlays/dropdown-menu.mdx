## 安装

先按[开始使用](/)配置组件仓库。

```sh
npx shadcn add @conteman/dropdown-menu
```

## Props

| 参数                 | 行为                                      |
| -------------------- | ----------------------------------------- |
| `open / defaultOpen` | boolean；受控打开状态或非受控初始状态。   |
| `onOpenChange`       | 变更或提交回调，副作用由应用处理。        |
| `disabled`           | boolean；禁用交互，默认 false。           |
| `variant`            | default / destructive；菜单项的操作语义。 |

导出：`DropdownMenu`、`DropdownMenuPortal`、`DropdownMenuTrigger`、`DropdownMenuContent`、`DropdownMenuGroup`、`DropdownMenuLabel`、`DropdownMenuItem`、`DropdownMenuCheckboxItem`、`DropdownMenuRadioGroup`、`DropdownMenuRadioItem`、`DropdownMenuSeparator`、`DropdownMenuShortcut`、`DropdownMenuSub`、`DropdownMenuSubTrigger`、`DropdownMenuSubContent`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import { useState } from "react";
import * as UI from "@/components/ui/dropdown-menu";
import { Button } from "@/components/ui/button";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  const [, setEmpty] = useState(false);
  return (
    <div
      id="preview"
      data-demo="dropdown-menu"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.DropdownMenu>
        <UI.DropdownMenuTrigger
          render={<Button variant="outline" className="min-h-11" />}
        >
          {text("更多操作", "More actions")}
        </UI.DropdownMenuTrigger>
        <UI.DropdownMenuContent>
          <UI.DropdownMenuGroup>
            <UI.DropdownMenuLabel>
              {text("项目操作", "Project actions")}
            </UI.DropdownMenuLabel>
            <UI.DropdownMenuItem onClick={() => setEmpty(true)}>
              {text("复制项目", "Duplicate project")}
            </UI.DropdownMenuItem>
            <UI.DropdownMenuItem disabled>
              {text("暂不可用", "Unavailable")}
            </UI.DropdownMenuItem>
            <UI.DropdownMenuSeparator />
            <UI.DropdownMenuItem
              variant="destructive"
              onClick={() => setEmpty(true)}
            >
              {text("移除示例", "Remove example")}
            </UI.DropdownMenuItem>
          </UI.DropdownMenuGroup>
        </UI.DropdownMenuContent>
      </UI.DropdownMenu>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
