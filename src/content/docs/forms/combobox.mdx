```sh
npx shadcn add @conteman/combobox
```

## Props

| 参数                   | 行为                                          |
| ---------------------- | --------------------------------------------- |
| `items`                | Base UI 选项集合，用于值与显示名称映射。      |
| `value / defaultValue` | 沿用底层组件的受控值或初始默认值。            |
| `onValueChange`        | 变更或提交回调，副作用由应用处理。            |
| `multiple`             | boolean；启用多值选择，value 与回调使用数组。 |

导出：`Combobox`、`ComboboxInput`、`ComboboxContent`、`ComboboxList`、`ComboboxItem`、`ComboboxGroup`、`ComboboxLabel`、`ComboboxCollection`、`ComboboxEmpty`、`ComboboxSeparator`、`ComboboxChips`、`ComboboxChip`、`ComboboxChipsInput`、`ComboboxTrigger`、`ComboboxValue`、`useComboboxAnchor`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import * as UI from "@/components/ui/combobox";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="combobox"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.Combobox items={["React", "Astro", "Vite"]}>
        <UI.ComboboxInput
          aria-label={text("搜索框架", "Search frameworks")}
          placeholder={text("选择或搜索…", "Choose or search…")}
        />
        <UI.ComboboxContent>
          <UI.ComboboxEmpty>
            {text("没有匹配选项", "No matching options")}
          </UI.ComboboxEmpty>
          <UI.ComboboxList>
            {(item: string) => (
              <UI.ComboboxItem key={item} value={item}>
                {item}
              </UI.ComboboxItem>
            )}
          </UI.ComboboxList>
        </UI.ComboboxContent>
      </UI.Combobox>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
