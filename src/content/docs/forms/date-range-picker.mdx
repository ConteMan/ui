## Props

| 参数           | 行为                                                       |
| -------------- | ---------------------------------------------------------- |
| `from / until` | string；日期为 YYYY-MM-DD，未设置时使用空字符串。          |
| `onChange`     | 变更或提交回调，副作用由应用处理。                         |
| `labels`       | 必填文案对象，包含可访问名称、反馈与操作名称。             |
| `dateOnly`     | boolean，默认 true；false 使用本地日期时间，不做时区转换。 |
| `validate`     | 可选校验函数，返回错误文字或 undefined。                   |

导出：`DateRange`、`DateRangeLabels`、`DateRangePicker`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import { useState } from "react";
import * as UI from "@/components/date-range-picker";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  const [range, setRange] = useState({ from: "", until: "" });
  return (
    <div
      id="preview"
      data-demo="date-range-picker"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.DateRangePicker
        from={range.from}
        until={range.until}
        onChange={setRange}
        labels={{
          trigger: text("日期范围", "Date range"),
          from: text("开始日期", "Start date"),
          until: text("结束日期（包含）", "End date (inclusive)"),
          apply: text("应用", "Apply"),
          clear: text("清除", "Clear"),
          invalid: text("请输入有效日期", "Enter valid dates"),
          reversed: text("结束日期不能早于开始日期", "End must follow start"),
          hint: text(
            "保留日历日期，时区转换由调用方完成。",
            "Calendar dates; the caller converts time zones.",
          ),
        }}
      />
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。

起止值是包含边界的日历日期标签；调用方负责转换为 API 时间戳。原生日期输入遵循浏览器语言，通过 labels 与 validate 注入应用语义。

可选 calendar 参数接收 locale、labels、weekStartsOn，启用日历范围选择。dateOnly 默认 true，from/until 为 YYYY-MM-DD 且结束日期包含；false 使用本地 datetime-local 字符串。时区与 API 边界转换由调用方完成。validate 返回错误文案时阻止提交。
