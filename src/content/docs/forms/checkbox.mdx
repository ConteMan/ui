## 安装

先按[开始使用](/)配置组件仓库。

```sh
npx shadcn add @conteman/checkbox
```

## Props

| 参数                       | 行为                                |
| -------------------------- | ----------------------------------- |
| `checked / defaultChecked` | 沿用底层组件的受控值或初始默认值。  |
| `onCheckedChange`          | 变更或提交回调，副作用由应用处理。  |
| `indeterminate`            | boolean；显示部分选中的复选框状态。 |
| `disabled`                 | boolean；禁用交互，默认 false。     |

导出：`Checkbox`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import { useState } from "react";
import * as UI from "@/components/ui/checkbox";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="checkbox"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <div className="grid gap-4">
        <label className="flex min-h-11 items-center gap-3">
          <UI.Checkbox defaultChecked />
          {text("接收更新", "Receive updates")}
        </label>
        <label className="flex min-h-11 items-center gap-3">
          <UI.Checkbox indeterminate />
          {text("部分选中", "Partially selected")}
        </label>
        <label className="flex min-h-11 items-center gap-3">
          <UI.Checkbox disabled />
          {text("不可用", "Unavailable")}
        </label>
      </div>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
