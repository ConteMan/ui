```sh
npx shadcn add @conteman/select
```

## Props

| 参数                   | 行为                                     |
| ---------------------- | ---------------------------------------- |
| `value / defaultValue` | 沿用底层组件的受控值或初始默认值。       |
| `onValueChange`        | 变更或提交回调，副作用由应用处理。       |
| `items`                | Base UI 选项集合，用于值与显示名称映射。 |
| `disabled`             | boolean；禁用交互，默认 false。          |

导出：`Select`、`SelectContent`、`SelectGroup`、`SelectItem`、`SelectLabel`、`SelectScrollDownButton`、`SelectScrollUpButton`、`SelectSeparator`、`SelectTrigger`、`SelectValue`。基础组件同时接受对应 Base UI 或原生元素参数；受控值需配套变更回调，默认值仅用于初始化内部状态。

## 使用

```tsx
import * as UI from "@/components/ui/select";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="select"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <div className="flex flex-wrap gap-3">
        <UI.Select
          items={[
            { value: "weekly", label: text("每周", "Weekly") },
            { value: "daily", label: text("每日", "Daily") },
          ]}
          defaultValue="weekly"
        >
          <UI.SelectTrigger
            aria-label={text("频率", "Frequency")}
            className="min-h-11 w-44"
          >
            <UI.SelectValue />
          </UI.SelectTrigger>
          <UI.SelectContent>
            <UI.SelectItem value="weekly">
              {text("每周", "Weekly")}
            </UI.SelectItem>
            <UI.SelectItem value="daily">{text("每日", "Daily")}</UI.SelectItem>
          </UI.SelectContent>
        </UI.Select>
        <UI.Select disabled>
          <UI.SelectTrigger aria-label={text("禁用选项", "Disabled select")}>
            <UI.SelectValue placeholder={text("不可用", "Unavailable")} />
          </UI.SelectTrigger>
        </UI.Select>
      </div>
    </div>
  );
}
```

## 状态与可访问性

通过 props 或 children 提供文字、可访问名称及反馈。表单控件支持 disabled 与 aria-invalid；静态展示组件通过内容表达状态。浮层沿用 Base UI 的焦点管理、Escape 关闭与焦点恢复。消费项目通过根元素的 `.dark` 切换主题。
