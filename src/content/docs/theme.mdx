## 安装

```sh
npx shadcn add @conteman/theme
```

先在 `components.json` 配置 `"@conteman": "https://ui.conteman.com/r/{name}.json"`。Button、Input、Table 会自动依赖这个 `registry:theme` 安装项；安装会更新已有的同名变量，请检查差异。

## 在项目中切换深色模式

shadcn 初始化为 Tailwind CSS 4 准备主题映射。确保入口 CSS 保留：

```css
@import "tailwindcss";
@custom-variant dark (&:where(.dark, .dark *));
```

在根元素切换 `.dark`，即可使用安装器写入的 `:root` 与 `.dark` 变量：

```ts
document.documentElement.classList.toggle("dark");
```

## Base UI 状态变体

主题同时提供 Base UI 状态属性的 Tailwind 变体，组件里的 `data-open:`、`data-horizontal:` 等简写依赖它们：

```css
@custom-variant data-open {
  &:where([data-state="open"]), &:where([data-open]:not([data-open="false"])) {
    @slot;
  }
}

@custom-variant data-horizontal {
  &:where([data-orientation="horizontal"]) {
    @slot;
  }
}
```

完整列表为 `data-open`、`data-closed`、`data-checked`、`data-unchecked`、`data-selected`、`data-disabled`、`data-active`、`data-horizontal`、`data-vertical`。`npx shadcn add @conteman/theme` 会把这九个变体与组件使用的 `no-scrollbar` 工具类写入入口 CSS。定义与 `shadcn/tailwind.css` 等价，两者同时存在不会报错；手动维护主题时复制整段，或引入 `@import "shadcn/tailwind.css"`。不要把组件里的简写改成 `data-[state=…]`，否则横向／纵向与开合状态会失效。

## 主题变量

主题包含 background、foreground、card、popover、primary、secondary、muted、accent、destructive、border、input、ring 及对应前景色，默认方角。主题值在 `registry.json` 的 `cssVars.light` / `cssVars.dark` 中维护。

## 文档站的桥接

Nimbus 自带 `data-mode="dark"`、系统主题跟随和持久化切换。本项目将注册表变量限定在 `.conteman-preview` 内，并将 Nimbus 的 `--nb-*` 颜色映射到组件变量。Base UI Portal 同样携带预览类，因此弹层不丢失主题。

生成的桥接 CSS 来自同一份主题数据。安装到项目的组件仍使用标准 `.dark`，不依赖文档站。

主题提供 chart-1 至 chart-5 图表色和 sidebar 系列变量，并安装 tw-animate-css。Chart 的 theme 配置可分别提供浅深色值，文档预览同时响应 data-mode。
