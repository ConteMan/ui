## Install

Configure the namespace in [Introduction](/en/) first.

```sh
npx shadcn add @conteman/skeleton
```

## Props

| Property     | Behavior                                                   |
| ------------ | ---------------------------------------------------------- |
| `className`  | string; Tailwind classes merged onto the root.             |
| `aria-label` | Caller-supplied text or accessible name; no built-in copy. |

Exports：`Skeleton`。Primitives also accept the corresponding Base UI or native element props. Controlled values require their change callback; default values initialize local state.

## Usage

```tsx
import * as UI from "@/components/ui/skeleton";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="skeleton"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <div
        aria-busy="true"
        aria-label={text("加载项目", "Loading project")}
        className="space-y-4"
      >
        <UI.Skeleton className="h-6 w-40" />
        <UI.Skeleton className="h-4 w-full" />
        <UI.Skeleton className="h-4 w-3/4" />
        <UI.Skeleton className="h-24 w-full" />
        <span role="status" className="sr-only">
          {text("加载中", "Loading")}
        </span>
      </div>
    </div>
  );
}
```

## States and accessibility

Supply visible text, accessible names and feedback through props or children. Form controls expose disabled and invalid states; static display components inherit their state from content. Overlays use Base UI focus management, Escape dismissal and focus restoration. Use `.dark` on the consuming root for dark mode.
