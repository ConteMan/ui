## Install

Configure the namespace in [Introduction](/en/) first.

```sh
npx shadcn add @conteman/empty
```

## Props

| Property    | Behavior                                       |
| ----------- | ---------------------------------------------- |
| `children`  | ReactNode content provided by the caller.      |
| `className` | string; Tailwind classes merged onto the root. |

Exports：`Empty`、`EmptyHeader`、`EmptyTitle`、`EmptyDescription`、`EmptyContent`、`EmptyMedia`。Primitives also accept the corresponding Base UI or native element props. Controlled values require their change callback; default values initialize local state.

## Usage

```tsx
import { useState } from "react";
import * as UI from "@/components/ui/empty";
import { Button } from "@/components/ui/button";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  const [empty, setEmpty] = useState(false);
  return (
    <div
      id="preview"
      data-demo="empty"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.Empty>
        <UI.EmptyHeader>
          <UI.EmptyTitle>{text("还没有项目", "No projects yet")}</UI.EmptyTitle>
          <UI.EmptyDescription>
            {text(
              "创建第一个项目后会显示在这里。",
              "Create your first project to see it here.",
            )}
          </UI.EmptyDescription>
        </UI.EmptyHeader>
        <UI.EmptyContent>
          <Button onClick={() => setEmpty(!empty)}>
            {empty
              ? text("示例已创建", "Example created")
              : text("创建项目", "Create project")}
          </Button>
        </UI.EmptyContent>
      </UI.Empty>
    </div>
  );
}
```

## States and accessibility

Supply visible text, accessible names and feedback through props or children. Form controls expose disabled and invalid states; static display components inherit their state from content. Overlays use Base UI focus management, Escape dismissal and focus restoration. Use `.dark` on the consuming root for dark mode.
