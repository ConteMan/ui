
## Props

| Property   | Behavior                                                          |
| ---------- | ----------------------------------------------------------------- |
| `variant`  | default / outline / muted; ItemMedia uses default / icon / image. |
| `size`     | default / sm / xs; content density.                               |
| `render`   | ReactElement or Base UI render callback; compose a custom root.   |
| `children` | ReactNode content provided by the caller.                         |

Exports：`Item`、`ItemMedia`、`ItemContent`、`ItemActions`、`ItemGroup`、`ItemSeparator`、`ItemTitle`、`ItemDescription`、`ItemHeader`、`ItemFooter`。Primitives also accept the corresponding Base UI or native element props. Controlled values require their change callback; default values initialize local state.

## Usage

```tsx
import { useState } from "react";
import * as UI from "@/components/ui/item";
import { Button } from "@/components/ui/button";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  const [empty, setEmpty] = useState(false);
  return (
    <div
      id="preview"
      data-demo="item"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.ItemGroup>
        <UI.Item variant="outline">
          <UI.ItemContent>
            <UI.ItemTitle>{text("示例项目", "Example project")}</UI.ItemTitle>
            <UI.ItemDescription>
              {text("组件组合示例", "Component composition example")}
            </UI.ItemDescription>
          </UI.ItemContent>
          <UI.ItemActions>
            <Button variant="outline" onClick={() => setEmpty(!empty)}>
              {empty ? text("已添加", "Added") : text("添加", "Add")}
            </Button>
          </UI.ItemActions>
        </UI.Item>
        <UI.ItemSeparator />
        <UI.Item>
          <UI.ItemContent>
            <UI.ItemTitle>{text("第二项", "Second item")}</UI.ItemTitle>
          </UI.ItemContent>
        </UI.Item>
      </UI.ItemGroup>
    </div>
  );
}
```

## States and accessibility

Supply visible text, accessible names and feedback through props or children. Form controls expose disabled and invalid states; static display components inherit their state from content. Overlays use Base UI focus management, Escape dismissal and focus restoration. Use `.dark` on the consuming root for dark mode.
