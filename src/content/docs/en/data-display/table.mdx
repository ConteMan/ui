## Install

Configure the namespace in [Introduction](/en/) first.

```sh
npx shadcn add @conteman/table
```

## Props

| Property    | Behavior                                       |
| ----------- | ---------------------------------------------- |
| `children`  | ReactNode content provided by the caller.      |
| `className` | string; Tailwind classes merged onto the root. |

Exports：`Table`、`TableHeader`、`TableBody`、`TableFooter`、`TableHead`、`TableRow`、`TableCell`、`TableCaption`。Primitives also accept the corresponding Base UI or native element props. Controlled values require their change callback; default values initialize local state.

## Usage

```tsx
import * as UI from "@/components/ui/table";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="table"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.Table aria-label={text("示例清单", "Example inventory")}>
        <UI.TableCaption>
          {text("示例数据", "Illustrative data")}
        </UI.TableCaption>
        <UI.TableHeader>
          <UI.TableRow>
            <UI.TableHead>{text("名称", "Name")}</UI.TableHead>
            <UI.TableHead>{text("状态", "Status")}</UI.TableHead>
          </UI.TableRow>
        </UI.TableHeader>
        <UI.TableBody>
          {["Button", "Input", "Table"].map((name) => (
            <UI.TableRow key={name}>
              <UI.TableCell>{name}</UI.TableCell>
              <UI.TableCell>{text("可使用", "Available")}</UI.TableCell>
            </UI.TableRow>
          ))}
        </UI.TableBody>
      </UI.Table>
    </div>
  );
}
```

## States and accessibility

Supply visible text, accessible names and feedback through props or children. Form controls expose disabled and invalid states; static display components inherit their state from content. Overlays use Base UI focus management, Escape dismissal and focus restoration. Use `.dark` on the consuming root for dark mode.
