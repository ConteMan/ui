Configure the namespace in [Introduction](/en/) first.

```sh
npx shadcn add @conteman/toggle
```

## Props

| Property                   | Behavior                                                                 |
| -------------------------- | ------------------------------------------------------------------------ |
| `pressed / defaultPressed` | Controlled state or initial default state from the underlying primitive. |
| `onPressedChange`          | Change or submit callback; application owns side effects.                |
| `variant`                  | default / outline; visual style.                                         |
| `disabled`                 | boolean; disable interaction, default false.                             |

Exports：`Toggle`、`toggleVariants`。Primitives also accept the corresponding Base UI or native element props. Controlled values require their change callback; default values initialize local state.

## Usage

```tsx
import * as UI from "@/components/ui/toggle";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="toggle"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <div className="flex flex-wrap gap-3">
        <UI.Toggle
          aria-label={text("加粗", "Bold")}
          variant="outline"
          className="min-h-11 min-w-11"
        >
          B
        </UI.Toggle>
        <UI.Toggle
          aria-label={text("斜体", "Italic")}
          defaultPressed
          className="min-h-11 min-w-11"
        >
          <em>I</em>
        </UI.Toggle>
        <UI.Toggle disabled aria-label={text("不可用", "Unavailable")}>
          U
        </UI.Toggle>
      </div>
    </div>
  );
}
```

## States and accessibility

Supply visible text, accessible names and feedback through props or children. Form controls expose disabled and invalid states; static display components inherit their state from content. Overlays use Base UI focus management, Escape dismissal and focus restoration. Use `.dark` on the consuming root for dark mode.
