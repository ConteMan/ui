## Props

| Property               | Behavior                                                      |
| ---------------------- | ------------------------------------------------------------- |
| `theme`                | light, dark or system, controlled by caller.                  |
| `containerAriaLabel`   | Caller-supplied text or accessible name; no built-in copy.    |
| `closeButtonAriaLabel` | Caller-supplied text or accessible name; no built-in copy.    |
| `toastOptions`         | Sonner toastOptions; duration, styling and per-toast options. |

Exports：`Toaster`。Primitives also accept the corresponding Base UI or native element props. Controlled values require their change callback; default values initialize local state.

## Usage

```tsx
import { useState, useEffect } from "react";
import * as UI from "@/components/ui/sonner";
import { Button } from "@/components/ui/button";
import { toast } from "sonner";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  const [theme, setTheme] = useState<"light" | "dark">("light");
  useEffect(() => {
    const update = () =>
      setTheme(
        document.documentElement.dataset.mode === "dark" ? "dark" : "light",
      );
    update();
    const observer = new MutationObserver(update);
    observer.observe(document.documentElement, {
      attributes: true,
      attributeFilter: ["data-mode"],
    });
    return () => observer.disconnect();
  }, []);
  return (
    <div
      id="preview"
      data-demo="sonner"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <div className="flex flex-wrap gap-3">
        <UI.Toaster
          theme={theme}
          containerAriaLabel={text("通知", "Notifications")}
          closeButton
          closeButtonAriaLabel={text("关闭通知", "Dismiss notification")}
        />
        <Button
          onClick={() => toast.success(text("已保存示例", "Example saved"))}
        >
          {text("成功通知", "Success notification")}
        </Button>
        <Button
          variant="outline"
          onClick={() =>
            toast.error(text("保存失败，请重试", "Save failed; try again"))
          }
        >
          {text("错误通知", "Error notification")}
        </Button>
      </div>
    </div>
  );
}
```

## States and accessibility

Supply visible text, accessible names and feedback through props or children. Form controls expose disabled and invalid states; static display components inherit their state from content. Overlays use Base UI focus management, Escape dismissal and focus restoration. Use `.dark` on the consuming root for dark mode.

Pass theme, containerAriaLabel and closeButtonAriaLabel. This wrapper does not require next-themes.
