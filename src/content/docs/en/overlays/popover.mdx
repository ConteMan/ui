## Props

| Property             | Behavior                                                         |
| -------------------- | ---------------------------------------------------------------- |
| `open / defaultOpen` | boolean; controlled open state or uncontrolled initial state.    |
| `onOpenChange`       | Change or submit callback; application owns side effects.        |
| `side / align`       | Popup side top/right/bottom/left and alignment start/center/end. |
| `children`           | ReactNode content provided by the caller.                        |

Exports：`Popover`、`PopoverContent`、`PopoverDescription`、`PopoverHeader`、`PopoverTitle`、`PopoverTrigger`。Primitives also accept the corresponding Base UI or native element props. Controlled values require their change callback; default values initialize local state.

## Usage

```tsx
import { useId } from "react";
import * as UI from "@/components/ui/popover";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);
  const id = useId();
  return (
    <div
      id="preview"
      data-demo="popover"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.Popover>
        <UI.PopoverTrigger
          render={<Button variant="outline" className="min-h-11" />}
        >
          {text("打开选项", "Open options")}
        </UI.PopoverTrigger>
        <UI.PopoverContent>
          <UI.PopoverTitle>
            {text("显示选项", "Display options")}
          </UI.PopoverTitle>
          <UI.PopoverDescription>
            {text("选项由调用方定义。", "Options are defined by the caller.")}
          </UI.PopoverDescription>
          <Label htmlFor={id}>{text("名称", "Name")}</Label>
          <Input id={id} defaultValue="Example" />
        </UI.PopoverContent>
      </UI.Popover>
    </div>
  );
}
```

## States and accessibility

Supply visible text, accessible names and feedback through props or children. Form controls expose disabled and invalid states; static display components inherit their state from content. Overlays use Base UI focus management, Escape dismissal and focus restoration. Use `.dark` on the consuming root for dark mode.
