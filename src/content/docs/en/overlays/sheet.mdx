Configure the namespace in [Introduction](/en/) first.

```sh
npx shadcn add @conteman/sheet
```

## Props

| Property             | Behavior                                                      |
| -------------------- | ------------------------------------------------------------- |
| `open / defaultOpen` | boolean; controlled open state or uncontrolled initial state. |
| `onOpenChange`       | Change or submit callback; application owns side effects.     |
| `side`               | top / right / bottom / left; SheetContent defaults to right.  |
| `closeLabel`         | Caller-supplied text or accessible name; no built-in copy.    |

Exports：`Sheet`、`SheetTrigger`、`SheetClose`、`SheetContent`、`SheetHeader`、`SheetFooter`、`SheetTitle`、`SheetDescription`。Primitives also accept the corresponding Base UI or native element props. Controlled values require their change callback; default values initialize local state.

## Usage

```tsx
import { useId } from "react";
import * as UI from "@/components/ui/sheet";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);
  const id = useId();
  return (
    <div
      id="preview"
      data-demo="sheet"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.Sheet>
        <UI.SheetTrigger render={<Button className="min-h-11" />}>
          {text("打开侧面板", "Open sheet")}
        </UI.SheetTrigger>
        <UI.SheetContent closeLabel={text("关闭", "Close")}>
          <UI.SheetHeader>
            <UI.SheetTitle>{text("编辑项目", "Edit project")}</UI.SheetTitle>
            <UI.SheetDescription>
              {text(
                "通过 Escape 或关闭按钮返回。",
                "Use Escape or the close button to return.",
              )}
            </UI.SheetDescription>
          </UI.SheetHeader>
          <div className="grid gap-3 p-4">
            <Label htmlFor={id}>{text("名称", "Name")}</Label>
            <Input id={id} defaultValue="Example" />
          </div>
          <UI.SheetFooter>
            <UI.SheetClose render={<Button />}>
              {text("完成", "Done")}
            </UI.SheetClose>
          </UI.SheetFooter>
        </UI.SheetContent>
      </UI.Sheet>
    </div>
  );
}
```

## States and accessibility

Supply visible text, accessible names and feedback through props or children. Form controls expose disabled and invalid states; static display components inherit their state from content. Overlays use Base UI focus management, Escape dismissal and focus restoration. Use `.dark` on the consuming root for dark mode.

The built-in close button is rendered only when closeLabel is supplied; otherwise compose an explicitly labelled Close control.
