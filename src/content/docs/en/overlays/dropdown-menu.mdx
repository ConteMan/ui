Configure the namespace in [Introduction](/en/) first.

```sh
npx shadcn add @conteman/dropdown-menu
```

## Props

| Property             | Behavior                                                      |
| -------------------- | ------------------------------------------------------------- |
| `open / defaultOpen` | boolean; controlled open state or uncontrolled initial state. |
| `onOpenChange`       | Change or submit callback; application owns side effects.     |
| `disabled`           | boolean; disable interaction, default false.                  |
| `variant`            | default / destructive; menu item semantics.                   |

Exports：`DropdownMenu`、`DropdownMenuPortal`、`DropdownMenuTrigger`、`DropdownMenuContent`、`DropdownMenuGroup`、`DropdownMenuLabel`、`DropdownMenuItem`、`DropdownMenuCheckboxItem`、`DropdownMenuRadioGroup`、`DropdownMenuRadioItem`、`DropdownMenuSeparator`、`DropdownMenuShortcut`、`DropdownMenuSub`、`DropdownMenuSubTrigger`、`DropdownMenuSubContent`。Primitives also accept the corresponding Base UI or native element props. Controlled values require their change callback; default values initialize local state.

## Usage

```tsx
import { useState } from "react";
import * as UI from "@/components/ui/dropdown-menu";
import { Button } from "@/components/ui/button";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  const [, setEmpty] = useState(false);
  return (
    <div
      id="preview"
      data-demo="dropdown-menu"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.DropdownMenu>
        <UI.DropdownMenuTrigger
          render={<Button variant="outline" className="min-h-11" />}
        >
          {text("更多操作", "More actions")}
        </UI.DropdownMenuTrigger>
        <UI.DropdownMenuContent>
          <UI.DropdownMenuGroup>
            <UI.DropdownMenuLabel>
              {text("项目操作", "Project actions")}
            </UI.DropdownMenuLabel>
            <UI.DropdownMenuItem onClick={() => setEmpty(true)}>
              {text("复制项目", "Duplicate project")}
            </UI.DropdownMenuItem>
            <UI.DropdownMenuItem disabled>
              {text("暂不可用", "Unavailable")}
            </UI.DropdownMenuItem>
            <UI.DropdownMenuSeparator />
            <UI.DropdownMenuItem
              variant="destructive"
              onClick={() => setEmpty(true)}
            >
              {text("移除示例", "Remove example")}
            </UI.DropdownMenuItem>
          </UI.DropdownMenuGroup>
        </UI.DropdownMenuContent>
      </UI.DropdownMenu>
    </div>
  );
}
```

## States and accessibility

Supply visible text, accessible names and feedback through props or children. Form controls expose disabled and invalid states; static display components inherit their state from content. Overlays use Base UI focus management, Escape dismissal and focus restoration. Use `.dark` on the consuming root for dark mode.
