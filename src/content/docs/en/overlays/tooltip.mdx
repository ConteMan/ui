## Install

Configure the namespace in [Introduction](/en/) first.

```sh
npx shadcn add @conteman/tooltip
```

## Props

| Property       | Behavior                                                         |
| -------------- | ---------------------------------------------------------------- |
| `delay`        | number; TooltipProvider hover delay in milliseconds.             |
| `children`     | ReactNode content provided by the caller.                        |
| `side / align` | Popup side top/right/bottom/left and alignment start/center/end. |

Exports：`Tooltip`、`TooltipTrigger`、`TooltipContent`、`TooltipProvider`。Primitives also accept the corresponding Base UI or native element props. Controlled values require their change callback; default values initialize local state.

## Usage

```tsx
import * as UI from "@/components/ui/tooltip";
import { Button } from "@/components/ui/button";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="tooltip"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.TooltipProvider>
        <UI.Tooltip>
          <UI.TooltipTrigger
            render={<Button variant="outline" className="min-h-11" />}
          >
            {text("悬停或聚焦", "Hover or focus")}
          </UI.TooltipTrigger>
          <UI.TooltipContent>
            {text(
              "键盘焦点同样显示说明。",
              "Keyboard focus also reveals this hint.",
            )}
          </UI.TooltipContent>
        </UI.Tooltip>
      </UI.TooltipProvider>
    </div>
  );
}
```

## States and accessibility

Supply visible text, accessible names and feedback through props or children. Form controls expose disabled and invalid states; static display components inherit their state from content. Overlays use Base UI focus management, Escape dismissal and focus restoration. Use `.dark` on the consuming root for dark mode.
