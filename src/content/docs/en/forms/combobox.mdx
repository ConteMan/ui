## Props

| Property               | Behavior                                                                 |
| ---------------------- | ------------------------------------------------------------------------ |
| `items`                | Base UI item collection mapping values to labels.                        |
| `value / defaultValue` | Controlled state or initial default state from the underlying primitive. |
| `onValueChange`        | Change or submit callback; application owns side effects.                |
| `multiple`             | boolean; enable multiple selection with array values and callbacks.      |

Exports：`Combobox`、`ComboboxInput`、`ComboboxContent`、`ComboboxList`、`ComboboxItem`、`ComboboxGroup`、`ComboboxLabel`、`ComboboxCollection`、`ComboboxEmpty`、`ComboboxSeparator`、`ComboboxChips`、`ComboboxChip`、`ComboboxChipsInput`、`ComboboxTrigger`、`ComboboxValue`、`useComboboxAnchor`。Primitives also accept the corresponding Base UI or native element props. Controlled values require their change callback; default values initialize local state.

## Usage

```tsx
import * as UI from "@/components/ui/combobox";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="combobox"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <UI.Combobox items={["React", "Astro", "Vite"]}>
        <UI.ComboboxInput
          aria-label={text("搜索框架", "Search frameworks")}
          placeholder={text("选择或搜索…", "Choose or search…")}
        />
        <UI.ComboboxContent>
          <UI.ComboboxEmpty>
            {text("没有匹配选项", "No matching options")}
          </UI.ComboboxEmpty>
          <UI.ComboboxList>
            {(item: string) => (
              <UI.ComboboxItem key={item} value={item}>
                {item}
              </UI.ComboboxItem>
            )}
          </UI.ComboboxList>
        </UI.ComboboxContent>
      </UI.Combobox>
    </div>
  );
}
```

## States and accessibility

Supply visible text, accessible names and feedback through props or children. Form controls expose disabled and invalid states; static display components inherit their state from content. Overlays use Base UI focus management, Escape dismissal and focus restoration. Use `.dark` on the consuming root for dark mode.
