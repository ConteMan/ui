Configure the namespace in [Introduction](/en/) first.

```sh
npx shadcn add @conteman/checkbox
```

## Props

| Property                   | Behavior                                                                 |
| -------------------------- | ------------------------------------------------------------------------ |
| `checked / defaultChecked` | Controlled state or initial default state from the underlying primitive. |
| `onCheckedChange`          | Change or submit callback; application owns side effects.                |
| `indeterminate`            | boolean; render the mixed checkbox state.                                |
| `disabled`                 | boolean; disable interaction, default false.                             |

Exports：`Checkbox`。Primitives also accept the corresponding Base UI or native element props. Controlled values require their change callback; default values initialize local state.

## Usage

```tsx
import { useState } from "react";
import * as UI from "@/components/ui/checkbox";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);

  return (
    <div
      id="preview"
      data-demo="checkbox"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <div className="grid gap-4">
        <label className="flex min-h-11 items-center gap-3">
          <UI.Checkbox defaultChecked />
          {text("接收更新", "Receive updates")}
        </label>
        <label className="flex min-h-11 items-center gap-3">
          <UI.Checkbox indeterminate />
          {text("部分选中", "Partially selected")}
        </label>
        <label className="flex min-h-11 items-center gap-3">
          <UI.Checkbox disabled />
          {text("不可用", "Unavailable")}
        </label>
      </div>
    </div>
  );
}
```

## States and accessibility

Supply visible text, accessible names and feedback through props or children. Form controls expose disabled and invalid states; static display components inherit their state from content. Overlays use Base UI focus management, Escape dismissal and focus restoration. Use `.dark` on the consuming root for dark mode.
