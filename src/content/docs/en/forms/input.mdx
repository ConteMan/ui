
## Props

| Property               | Behavior                                                                               |
| ---------------------- | -------------------------------------------------------------------------------------- |
| `value / defaultValue` | Controlled state or initial default state from the underlying primitive.               |
| `onChange`             | Change or submit callback; application owns side effects.                              |
| `disabled`             | boolean; disable interaction, default false.                                           |
| `aria-invalid`         | boolean; set true for invalid input and associate error content with aria-describedby. |

Exports：`Input`。Primitives also accept the corresponding Base UI or native element props. Controlled values require their change callback; default values initialize local state.

## Usage

```tsx
import { useId, useState } from "react";
import * as UI from "@/components/ui/input";
import { Label } from "@/components/ui/label";

export default function Example({ locale = "zh" }: { locale?: "zh" | "en" }) {
  const english = locale === "en";
  const text = (zh: string, en: string) => (english ? en : zh);
  const id = useId();

  return (
    <div
      id="preview"
      data-demo="input"
      className="conteman-preview min-w-0 space-y-4 border border-border p-4 sm:p-6"
    >
      <div className="grid gap-3">
        <Label htmlFor={id}>{text("项目名称", "Project name")}</Label>
        <UI.Input id={id} placeholder={text("输入名称…", "Enter a name…")} />
        <UI.Input
          aria-label={text("禁用输入", "Disabled input")}
          disabled
          value="Example"
        />
        <UI.Input
          aria-label={text("错误示例", "Invalid example")}
          aria-invalid="true"
          aria-describedby={id + "-error"}
          defaultValue="!"
        />
        <p id={id + "-error"} role="alert" className="text-destructive">
          {text("名称至少两个字符。", "Use at least two characters.")}
        </p>
      </div>
    </div>
  );
}
```

## States and accessibility

Supply visible text, accessible names and feedback through props or children. Form controls expose disabled and invalid states; static display components inherit their state from content. Overlays use Base UI focus management, Escape dismissal and focus restoration. Use `.dark` on the consuming root for dark mode.
